# FOAY0001 — Array Index Out of Bounds

A dynamic error is raised when an array is accessed with an index that is less than 1 or greater than the array size.

## Type

Dynamic error

## Description

Array access is 1-based. This error occurs when accessing an array member at an invalid position.

## Examples

```xquery
[10, 20, 30](0)
(: Error: FOAY0001 — index 0 is less than 1 :)

[10, 20, 30](4)
(: Error: FOAY0001 — index 4 exceeds size 3 :)

let $a := []
return $a(1)
(: Error: FOAY0001 — empty array :)
```
