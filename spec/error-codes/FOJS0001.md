# FOJS0001 — Invalid JSON

A dynamic error is raised when a string supplied to a JSON parsing function is not valid JSON.

## Type

Dynamic error

## Description

The input to `fn:parse-json`, `fn:json-doc`, or `fn:json-to-xml` does not conform to JSON syntax.

## Examples

```xquery
fn:parse-json("{invalid}")
(: Error: FOJS0001 :)

fn:parse-json("{'single-quotes': 'not valid'}")
(: Error: FOJS0001 — JSON requires double quotes :)
```
