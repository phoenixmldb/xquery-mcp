# XPST0081 — Undefined Namespace Prefix

A static error is raised when a QName uses a namespace prefix that has not been declared.

## Type

Static error

## Description

A namespace prefix used in an element name, attribute name, function call, or type reference has no corresponding namespace declaration.

## Examples

```xquery
(: Undeclared prefix in element :)
<ns:element/>
(: Error: XPST0081 if 'ns' not declared :)

(: Undeclared prefix in option :)
declare option foo:bar "value";
(: Error: XPST0081 if 'foo' not declared :)
```
