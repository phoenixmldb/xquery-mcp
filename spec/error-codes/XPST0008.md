# XPST0008 — Undefined Name

A static error is raised when an expression references a name (variable, type, namespace prefix) that is not defined in the static context.

## Type

Static error

## Description

This error occurs when the processor encounters a reference to a name that has not been declared or is not in scope.

## Common Causes

- Referencing a variable that has not been declared
- Using an undeclared namespace prefix
- Typo in a variable or function name
- Variable referenced outside its scope

## Examples

```xquery
(: Undefined variable :)
$undefined-var
(: Error: XPST0008 :)

(: Variable out of scope :)
for $x in (1, 2, 3) return $x,
$x
(: Error: XPST0008 — $x is not in scope after the FLWOR :)

(: Undeclared prefix :)
//ns:element
(: Error: XPST0008 if 'ns' is not declared :)
```
