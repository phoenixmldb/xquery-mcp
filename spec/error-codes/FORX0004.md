# FORX0004 — Invalid Replacement String

A dynamic error is raised when the replacement string in `fn:replace` is invalid.

## Type

Dynamic error

## Description

The replacement string contains an invalid reference, such as a `$` not followed by a digit, or a `\` not followed by `$` or `\`.

## Examples

```xquery
fn:replace("hello", "(h)", "$a")
(: Error: FORX0004 — $ not followed by digit :)

fn:replace("hello", "(h)", "\x")
(: Error: FORX0004 — \ not followed by $ or \ :)
```
