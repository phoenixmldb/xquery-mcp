# XPTY0020 — Context Item Not a Node

A type error is raised when the context item in an axis step is not a node.

## Type

Type error (static or dynamic)

## Description

Axis steps (e.g., `child::`, `parent::`, `/`) require the context item to be a node. This error occurs when an axis step is evaluated with a non-node context item (such as an atomic value, map, or array).

## Examples

```xquery
(: Axis step on atomic value :)
let $x := 42
return $x/child::*
(: Error: XPTY0020 :)

(: Path on string :)
"hello"/foo
(: Error: XPTY0020 :)
```
