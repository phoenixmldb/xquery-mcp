# FORX0003 — Regular Expression Matches Zero-Length String

A dynamic error is raised when the pattern in `fn:replace` or `fn:tokenize` matches a zero-length string.

## Type

Dynamic error

## Description

In `fn:replace` and `fn:tokenize`, the pattern must not match a zero-length string, because this would create an infinite loop.

## Examples

```xquery
fn:tokenize("hello", "a?")
(: Error: FORX0003 — "a?" matches zero-length string :)

fn:replace("hello", ".*?", "x")
(: Error: FORX0003 :)
```
