# XPDY0050 — Invalid treat Expression Type

A dynamic error is raised when the operand of a `treat as` expression does not match the specified type.

## Type

Dynamic error

## Description

The `treat as` expression is a runtime type assertion. Unlike `cast`, it does not convert the value — it simply verifies the type. If the value does not match, this error is raised.

## Examples

```xquery
(: Treating string as integer :)
"hello" treat as xs:integer
(: Error: XPDY0050 :)

(: Wrong cardinality :)
(1, 2) treat as xs:integer
(: Error: XPDY0050 — expected exactly one :)
```
