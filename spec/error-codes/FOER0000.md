# FOER0000 — Unidentified Error

The error raised by `fn:error()` when called with no arguments.

## Type

Dynamic error

## Description

This is the default error code used by `fn:error()`. It represents a user-initiated error with no specific error code.

## Examples

```xquery
(: Raise default error :)
fn:error()
(: Error: FOER0000 :)

(: Raise custom error :)
fn:error(xs:QName("app:invalid-input"), "The input is invalid")
(: Error: app:invalid-input — not FOER0000 :)
```
