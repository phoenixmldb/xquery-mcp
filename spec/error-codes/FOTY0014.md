# FOTY0014 — Function Item Has No String Value

A dynamic error is raised when `fn:string` or `fn:data` is applied to a function item.

## Type

Dynamic error

## Description

Function items (including maps, arrays, and named functions) do not have a string value. Attempting to convert them to a string raises this error.

## Examples

```xquery
fn:string(function($x) { $x + 1 })
(: Error: FOTY0014 :)

fn:string(map{"a": 1})
(: Error: FOTY0014 :)

fn:data([1, 2, 3])
(: Error: FOTY0014 :)
```
