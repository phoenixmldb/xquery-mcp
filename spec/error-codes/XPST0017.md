# XPST0017 — Unknown Function

A static error is raised when a function call references a function that is not available in the static context.

## Type

Static error

## Description

The processor cannot find a function with the given name and arity (number of arguments). This includes both built-in functions and user-declared functions.

## Common Causes

- Typo in function name
- Wrong number of arguments
- Missing module import
- Wrong namespace prefix

## Examples

```xquery
(: Misspelled function :)
fn:uper-case("hello")
(: Error: XPST0017 :)

(: Wrong arity :)
fn:substring("hello")
(: Error: XPST0017 — substring requires 2 or 3 arguments :)

(: Missing import :)
math:square(5)
(: Error: XPST0017 if math module not imported :)
```
