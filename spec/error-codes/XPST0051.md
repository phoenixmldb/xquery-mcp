# XPST0051 — Unknown Atomic Type

A static error is raised when a SequenceType references an atomic type that is not defined in the in-scope schema types.

## Type

Static error

## Description

The type name used in a type declaration, `cast as`, `instance of`, or other SequenceType context is not recognized.

## Common Causes

- Typo in type name (e.g., `xs:sting` instead of `xs:string`)
- Using a type from an unimported schema
- Using an undeclared namespace prefix

## Examples

```xquery
(: Unknown type :)
"hello" cast as xs:sting
(: Error: XPST0051 :)

(: Unimported type :)
$value instance of my:customType
(: Error: XPST0051 if 'my' namespace types not imported :)
```
