# FORG0006 — Invalid Argument Type

A dynamic error is raised when an argument to a function has the wrong type.

## Type

Dynamic error

## Description

This error typically occurs when computing the effective boolean value (EBV) of an invalid value, or when a function receives an argument of an unexpected type.

## Common Causes

- Computing EBV of a sequence starting with an atomic value that has more than one item
- Computing EBV of a function item (map, array, or function)
- Passing incompatible types to aggregate functions (`fn:sum`, `fn:avg`, etc.)

## Examples

```xquery
(: EBV of multi-item atomic sequence :)
if ((1, 2)) then "yes" else "no"
(: Error: FORG0006 :)

(: EBV of a map :)
boolean(map{"a": 1})
(: Error: FORG0006 :)

(: Sum of mixed types :)
fn:sum(("hello", 42))
(: Error: FORG0006 :)
```
