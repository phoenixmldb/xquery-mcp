# XQDY0137 — Duplicate Map Key

A dynamic error is raised when a map constructor contains duplicate keys.

## Type

Dynamic error

## Description

Map constructors require all keys to be unique. If two or more entries have equal keys (compared using `eq`), this error is raised.

## Examples

```xquery
map { "a": 1, "a": 2 }
(: Error: XQDY0137 :)

map { 1: "one", 1.0: "one-point-zero" }
(: Error: XQDY0137 — 1 eq 1.0 is true :)
```
