# XPDY0002 — Undefined Context Item

A dynamic error is raised when an expression depends on the context item, position, or size, but they are not defined.

## Type

Dynamic error

## Description

This error occurs when `.`, `position()`, `last()`, or a relative path expression is used in a context where no focus has been established.

## Common Causes

- Using `.` at the top level of a query with no context document
- Calling `fn:string()` or `fn:number()` with no argument and no context item
- Relative path in a function body with no context

## Examples

```xquery
(: No context item at top level :)
.
(: Error: XPDY0002 :)

(: Relative path with no context :)
child::element()
(: Error: XPDY0002 :)

(: Function call requiring context :)
fn:string()
(: Error: XPDY0002 if no context item :)
```
