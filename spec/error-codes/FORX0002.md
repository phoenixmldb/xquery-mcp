# FORX0002 — Invalid Regular Expression

A dynamic error is raised when a regular expression pattern is invalid.

## Type

Dynamic error

## Description

The regular expression string passed to `fn:matches`, `fn:replace`, `fn:tokenize`, or `fn:analyze-string` is not a valid XPath regular expression.

## Common Causes

- Unescaped special characters
- Unbalanced parentheses or brackets
- Invalid character class
- Invalid quantifier

## Examples

```xquery
fn:matches("test", "[invalid")
(: Error: FORX0002 — unbalanced bracket :)

fn:matches("test", "*")
(: Error: FORX0002 — quantifier without target :)
```
