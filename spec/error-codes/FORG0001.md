# FORG0001 — Invalid Cast

A dynamic error is raised when a value cannot be cast to the required type.

## Type

Dynamic error

## Description

Raised when a cast or constructor fails because the source value is not a valid lexical representation of the target type.

## Common Causes

- Casting a non-numeric string to a numeric type
- Casting an invalid date string to `xs:date`
- Casting a value that is out of range

## Examples

```xquery
xs:integer("hello")
(: Error: FORG0001 :)

xs:date("not-a-date")
(: Error: FORG0001 :)

xs:decimal("12.34.56")
(: Error: FORG0001 :)
```
