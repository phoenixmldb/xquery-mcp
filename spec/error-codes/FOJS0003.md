# FOJS0003 — Duplicate JSON Key

A dynamic error is raised when JSON parsing encounters a duplicate key and the `duplicates` option is set to `"reject"`.

## Type

Dynamic error

## Description

By default, duplicate keys in JSON are handled silently (using the first or last value). When the `duplicates` option is set to `"reject"`, this error is raised instead.

Also raised by `map:merge` with `duplicates` option `"reject"`.

## Examples

```xquery
fn:parse-json('{"a":1, "a":2}', map{"duplicates":"reject"})
(: Error: FOJS0003 :)

map:merge((map{"a":1}, map{"a":2}), map{"duplicates":"reject"})
(: Error: FOJS0003 :)
```
