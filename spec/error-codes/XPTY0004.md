# XPTY0004 — Type Error

A type error is raised during static analysis or evaluation when an expression's type does not match the expected type.

## Type

Type error (static or dynamic)

## Description

This is the most common type error in XQuery. It occurs when a value's type does not match the required type of a function parameter, operator, or expression context.

## Common Causes

- Passing a string where a number is expected (or vice versa)
- Comparing incompatible types
- Wrong cardinality (sequence where single item expected)
- Arithmetic on non-numeric types

## Examples

```xquery
(: Arithmetic on string :)
"hello" + 1
(: Error: XPTY0004 :)

(: Comparison of incompatible types :)
"hello" > 42
(: Error: XPTY0004 :)

(: Sequence where single item expected :)
let $x as xs:integer := (1, 2, 3)
return $x
(: Error: XPTY0004 :)
```
