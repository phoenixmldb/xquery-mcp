# XPST0003 — Static Syntax Error

A static error is raised when the query does not conform to the XQuery grammar.

## Type

Static error

## Description

This error indicates that the XQuery processor cannot parse the query because it contains a syntax error. This is one of the most common errors and is always detected at compile time.

## Common Causes

- Missing keywords (`then`, `else`, `return`, etc.)
- Unbalanced parentheses, brackets, or braces
- Invalid expression syntax
- Missing semicolons in prolog declarations
- Typos in keywords

## Examples

```xquery
(: Missing 'return' keyword :)
for $x in (1, 2, 3)
$x * 2
(: Error: XPST0003 :)

(: Missing 'else' branch (XQuery 3.1) :)
if ($x > 0) then "positive"
(: Error: XPST0003 in XQuery 3.1 (allowed in 4.0) :)

(: Unbalanced braces :)
<result>{ $value </result>
(: Error: XPST0003 :)
```
