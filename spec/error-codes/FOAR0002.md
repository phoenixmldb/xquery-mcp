# FOAR0002 — Division by Zero

A dynamic error is raised when dividing by zero in `xs:decimal` or `xs:integer` arithmetic.

## Type

Dynamic error

## Description

Division or modulo by zero for `xs:integer` and `xs:decimal` types. Note that for `xs:double` and `xs:float`, division by zero produces `INF`, `-INF`, or `NaN` per IEEE 754 — no error is raised.

## Examples

```xquery
(: Integer division by zero :)
1 div 0
(: Error: FOAR0002 :)

(: Decimal division by zero :)
1.0 div 0.0
(: Error: FOAR0002 :)

(: idiv by zero :)
10 idiv 0
(: Error: FOAR0002 :)

(: Double division by zero — no error :)
1.0e0 div 0.0e0
(: Result: INF :)

(: Modulo by zero :)
10 mod 0
(: Error: FOAR0002 :)
```
