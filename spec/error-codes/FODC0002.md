# FODC0002 — Document Not Found

A dynamic error is raised when `fn:doc` cannot retrieve a resource at the given URI.

## Type

Dynamic error

## Description

The URI provided to `fn:doc()` does not resolve to an available XML document, or the retrieved resource is not valid XML.

## Common Causes

- File does not exist
- URI is malformed
- Resource is not well-formed XML
- Network error for HTTP URIs

## Examples

```xquery
fn:doc("nonexistent.xml")
(: Error: FODC0002 :)

fn:doc("http://example.com/404")
(: Error: FODC0002 :)
```
