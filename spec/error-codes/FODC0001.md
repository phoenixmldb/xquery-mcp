# FODC0001 — No Context Document

A dynamic error is raised when `fn:doc` or `fn:collection` is called and no default document or collection is available.

## Type

Dynamic error

## Description

The function requires a document or collection but none has been configured in the dynamic context.

## Examples

```xquery
fn:doc(())
(: May raise FODC0001 in some implementations :)
```
